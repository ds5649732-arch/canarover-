# canarover-
A rover for worker working in sewers .
<img width="1920" height="1080" alt="Screenshot 2026-11-18 233348" src="https://github.com/user-attachments/assets/746dc759-537f-48cd-ab99-c1d9d4035ee9" />

This project is aimed to make an experimental rover that can measure levels of harmful gases in any sewer before workers enter in it and if the levels of gases is high it would automatically start the fan installed in sewers .
It uses different sensors such as :
MQ-04 modules,

DFRobot Gravity I2C oxygen sensor (SEN0322),

MQ-136,

BME280,

MH-Z19B or C, 0 to 10,000 ppm version,

PURPOSE :

This project has a very simple purpose to make a simple experimental rover that can measure levels of harmful gases in sewers before workers enter it and if it comes above safe limit set in rover it will raise alarm and start an exhaust fan installed near manhole to create ventilation in sewer . 

Through this kind of rovers we can ensure safety of worker who enters sewers to repair them or for any other work.

And ofcourse canarover will not enter an actuall sewer for testing rather I will make an sewer like closed structure to test the rover .

WHY I MADE IT ?

In india cleaning sewers manually by an human is very common and in most cases workers die because of toxic gas they have inhale for such a long time so I tought to find a solution to this problem then I came up with this idea ,although my rover is not first rover to be made for this purpose but i think that I should  even try to make one .
